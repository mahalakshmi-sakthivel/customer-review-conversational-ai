# Customer Review Conversational AI

An AI-powered conversational platform for customer review interactions.

## Technology Stack
- Frontend: React
- Backend: Spring Boot
- Database: PostgreSQL
- Cache / supporting services: Redis
- Authentication: JWT and role-based authorization
